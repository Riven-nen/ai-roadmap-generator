# Documentation

This folder contains the user manual and the system test report.

- [User Manual](./USER_MANUAL.md) — simple English guide for students, professors, and administrators.
- [System Test Report](./SYSTEM_TEST_REPORT.md) — test scope, results, fixes, and known limitations.

Start with the User Manual if you are using the system. Read the Test Report if you want to know what was verified and what still needs a manual browser walkthrough.
